Tool: `kwr` (Ahrefs free tools) against the shared `kwr mint` token server. 5 batches:
`seeds.json` (24 generator seeds), `seeds2.json` (22 seeds + 6 SERPs), `mine.json` (12 traffic +
6 seeds), `mine2.json` (6 SERPs + 6 seeds + 15 KD), `mine3.json` (15 traffic).
513 unique keyword ideas and 124 unique question ideas merged; 47 of them traffic-proven on a
page that already ranks. 172 kept below.

The competitor set that decided the copy: `magicui.design/docs/components/confetti` is the only
component-library page ranking on all four head terms (485 visits/mo). `preline.co/docs/components/confetti.html`
owns the CSS cluster from #1. `kirilv.com/canvas-confetti` + `github.com/catdad/canvas-confetti` own
the canvas cluster. `lottiefiles.com/free-animations/confetti` and `enchanted.media` own the
platform-adjacent cluster (GIF, overlay, PowerPoint) with far more volume than the code cluster -
which is why angle F is answered in the FAQ instead of ignored.

### What the empty results mean

`generator` returned 0-3 rows for `confetti on success`, `confetti success page`,
`react confetti alternative`, `confetti ui component`, `how to add confetti to react app`,
`how to create confetti animation in javascript`, `nextjs confetti`, `shadcn confetti`,
`confetti react component` and `confetti animation for website`. Ahrefs has no volume bucket for
them, which means low search volume, not zero intent - they are the phrasings a developer types
into an assistant rather than a search box. They are kept and answered in the FAQ, since the FAQ
block is what an answer engine quotes.

`serp` returned 0 results for `confetti component`, `react confetti component` and
`confetti on click`. Nobody owns those SERPs. That is why `Component` is in the title.
