# installation - keyword research

Primary: tailwind alternative (KD 1, 150/mo proven, ranks for: reddit #1 / flyonui #2 / tinyhref #4 / areknawo #6 / kombai #9)
Secondary: alternatives to tailwind css (350/mo, KD 0), tailwind alternatives (200/mo, KD 0), what is the best css framework for react (200/mo), next js components (100/mo, KD 7)

## The finding that shaped the page

A docs installation page earns brand traffic and almost nothing else. Every
comparable in the sample tells the same story:

| Installation page                              | Traffic | What it actually ranks for                         |
| ---------------------------------------------- | ------- | -------------------------------------------------- |
| `ui.shadcn.com/docs/installation`              | 3.2K/mo | `shadcn` 36K, `shadcn/ui` 1.6K, `shadcnui` 450     |
| `mui.com/material-ui/getting-started/install…` | 3.7K/mo | `material ui react` 1.2K, `mui install` 200        |
| `chakra-ui.com/docs/get-started/installation`  | 348/mo  | `chakra ui` 14K — and `chakra ui install` **0/mo** |
| `mantine.dev/getting-started/`                 | 234/mo  | `mantine` 1.8K, `mantine ui` 150                   |
| `daisyui.com/docs/install/`                    | 157/mo  | `daisyui` 900, `daisy ui` 400                      |
| `magicui.design/docs/installation`             | 95/mo   | `magic ui` 4.9K — one keyword, nothing else        |
| `tailwindcss.com/docs/installation`            | 5/mo    | `postcss tailwind` 10 — that is the whole list     |
| `ant.design/docs/react/introduce`              | 5/mo    | `antd npm` **0/mo**                                |

The generic install phrasings these pages own are worth nothing: `chakra ui
install` 0/mo, `antd npm` 0/mo, `mui installation` 70/mo, `material ui install`
80/mo. Tailwind's own installation page — on a domain with millions of visits —
pulls **five** visits a month. There is no such thing as generic
install-keyword traffic; there is only brand traffic, and Zyncat has no brand
demand yet.

So the page cannot be built on install phrasing. It has to be built on the
_decision_ that sends someone to an install page in the first place — and the
one decision this page's facts answer is "what do I use instead of Tailwind."

## The tailwind-alternative cluster is the whole opportunity

Seven pages split ~890/mo between them, and the entire cluster comes back **KD
0-2**. Not one of the incumbents is a component library's own docs — they are a
Svelte subreddit thread, four listicles and a GitHub list.

| Page                                                     | Traffic | Owns                                                                                                               |
| -------------------------------------------------------- | ------- | ------------------------------------------------------------------------------------------------------------------ |
| `reddit.com/r/sveltejs/…/alternatives_to_tailwind`       | 487/mo  | #1 on `alternatives to tailwind css`, `tailwind alternatives`, `tailwind alternative`, `tailwind css alternatives` |
| `flyonui.com/blog/tailwind-css-alternatives/`            | 208/mo  | `alternatives to tailwind css` #2 (350), `tailwind alternatives` #1 (200)                                          |
| `github.com/tinyhref/tailwind-alternatives`              | 99/mo   | `tailwind competitors` #1 (40), `tailwind alternative` #4                                                          |
| `kombai.com/tailwind/tailwind-alternatives…`             | 59/mo   | `tailwindcss alternatives` #4 (40)                                                                                 |
| `tailgrids.com/blog/tailwind-plus-alternatives`          | 41/mo   | `tailwind alternatives` #6                                                                                         |
| `areknawo.com/top-4-tailwind-css-alternatives-for-2021/` | 34/mo   | still ranking a 2021 post on five of the cluster's terms                                                           |
| `daisyui.com/alternative/tailwindui/`                    | 17/mo   | `tailwind alternatives` #1 (50)                                                                                    |

Two things fall out of that. A five-year-old blog post and a Reddit thread hold
the top of a KD 0-1 SERP, so difficulty is not the obstacle. And the page that
would beat them is the one that stops listing alternatives and _is_ one — with
the install command on it, which is exactly what this page is.

`daisyui.com/alternative/tailwindui/` is the proof of concept from a library
that already does this: a dedicated "alternative to X" page inside the docs,
earning 17/mo at #1 with a page that exists to convert.

## Rejected: the homograph seeds

Six of the twenty-four seeds returned a subject that is not software at all,
and they are recorded here so the next agent does not re-run them.

- **`installation`** - home services, top to bottom: `garage door installation`,
  `hvac installation`, `water heater installation`, `ev charger installation`,
  all >10K. The questions are `how much does carpet installation cost` and
  `what is installation art`. The page's own name is unusable as a keyword.
- **`getting started`** - a 2017 Morgan Freeman film (`just getting started
cast`), bow hunting, vermicomposting, and a run of medical questions
  (`why have i started getting migraines`).
- **`new project`** - Project Runway. Every idea row above <100 is either the
  show's air dates or a Dubai property development.
- **`create app`** - no-code app builders and `create app password gmail`.
- **`setup guide`** - turtle tanks, hydroponics, army uniforms, Starlink.
- **`install package`** - R (`install package r`), Python, Linux distro
  packaging, and beekeeping (`how to install a package of bees in a hive`).
- **`package manager`** / **`cli tool`** - `uv`, `winget`, `apt`, and Claude
  Code / Codex respectively. Real dev intent, wrong dev intent.

## Rejected: real dev clusters that belong elsewhere

- **`install react` (1000/mo, react.dev #2)** - installing React itself.
  `react.dev/learn/installation` takes 9.1K/mo and
  `react.dev/learn/creating-a-react-app` 20.1K/mo on `create react app` 7.9K.
  Different subject; nobody typing it wants a component library.
- **`react component library` (600/mo), `react ui library` (500/mo), `ui library`
  (600/mo), `ui library for react` (250/mo), `best react ui library` (150/mo),
  `react ui components` (400/mo), `react ui framework` (300/mo)** - proven and
  valuable, but **claimed by the sibling `introduction` page**. Recorded as a
  collision, not a rejection: the terms are real, they are just not this page's.
  Owned today by `untitledui.com/react` (2.3K/mo) and
  `untitledui.com/blog/react-component-libraries` (1.5K/mo).
- **`component library` (500/mo), `design system examples` (600/mo), `design
system components` (200/mo)** - `component.gallery` at 4.9K/mo. Category head
  terms, also `introduction`'s.
- **`css framework` (600/mo), `css frameworks` (1400/mo), `css library`
  (300/mo), `best css framework` (200/mo)** - Zyncat ships components, not
  utility classes. Claiming the bare framework terms would be a different
  subject. The _React-qualified_ rows are kept instead (see below) because the
  SERP for those already answers with component libraries: GeeksforGeeks' "Top
  10 CSS Frameworks for React" lists MUI, Chakra and Ant Design.
- **`css library for react`** - proven at 50/mo but **KD 62 (Hard)**. Kept out
  of the title and out of `keywords`; the cheaper synonyms carry the cluster.
- **`headless ui` (600/mo)** - Tailwind Labs' unstyled primitives.
  `headlessui.com` takes 5.6K/mo. Different product category.
- **`tailwind components` (700/mo), `tailwind ui` (6800/mo)** - `hyperui.dev`
  4.7K/mo, `flyonui.com` 6.5K/mo. Zyncat is not a Tailwind component set, so
  these would be a false promise. `tailwind alternative` is the honest half of
  that traffic.
- **Next.js config long tail** - `transpilepackages`, `use client`,
  `nextjs app router where to put components`, `zero dependencies`: every row
  came back `<100` with no page earning measurable traffic from them. Real page
  facts, so they went into the FAQ as prose rather than into `keywords`.

## Open questions

None. Every FAQ claim is verifiable in `README.md`,
`apps/docs/components/pages/installation.tsx` or `packages/zyncat-ui/src/`:
the four init steps, `--yes` / `--pm` / `-v` flags, lockfile-and-`packageManager`
detection, Node 18+ (`engines`), React `^19` peer, no barrel entry, bundled
icons, and `'use client'` surviving the build so no `transpilePackages` is
needed.
