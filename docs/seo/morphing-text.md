## What Step 4 actually found

The subject's own name is worth almost nothing and the category above it is worth
a lot. `kwr traffic https://magicui.design/docs/components/morphing-text` returns
**2 visits/mo, $0 value, one ranking keyword**: `text morph` at position 1, worth 20. Motion-primitives sits at #2 on the same term for 6 visits/mo. Nobody is
earning from "morphing text" as a phrase — `serp "morphing text"`,
`serp "morphing text animation"` and `serp "gooey text effect"` all return zero
rows, which is the tool saying there is no measurable SERP there.

The money in this space is one rung up. magicui's sibling `text-animate` page
earns **740/mo** on `text animation` (#3, 2200), `text animations` (#4, 200),
`animated text` (#9, 350), `animate text` (#7, 200) and `font animation`
(#7, 200). Prismic's CSS article earns 2K/mo on the `css text animation` cluster.
Jitter earns 9.4K/mo on `text animation` at #1 — but as a video-template tool, so
that head term's intent is split between "component" and "make me a video".

So the page is titled for the name people use for this exact effect, and the copy
reaches up into `text animation` / `react text animation` where the proven clicks
are, without claiming to be a generic text-animation index.

## Facts the copy is allowed to claim

Read from `src/components/expressive/morphing-text/MorphingText.tsx`, its CSS, `MorphingText.usage.md`, `src/engine/loop.ts` and `apps/docs/components/playground.tsx`:

- Props: `words: string[]`, `hold?: number` (ms, default 1500), `speed?: number` (default 1), `className`, `style`, `htmlProps`. Fewer than two words renders as still type.
- `hold` and `speed` are read from refs inside the loop callback, so both are sampled live every frame.
- The morph itself is a fixed 900ms (`MORPH_MS`).
- The effect is a per-letter CSS `blur()` plus one SVG filter — `feGaussianBlur` into an `feColorMatrix` alpha threshold — attached to the stage only while a morph is in flight (`fuse()`).
- Hover: `pointerenter`/`pointerleave` set `cycle.held`; listeners are only attached when motion is not reduced. A morph already past the hold point still finishes.
- The hairline rule interpolates between the two measured word widths and heats toward `--accent`.
- Retunable properties: `--morphing-text-ink | size | weight | leading | tracking | smear | rule-ink | rule-accent | rule-height | rule-gap | rule-rest | rule-lift`.
- a11y: the current word is written to a visually hidden `.morphing-text__label`; the animated stage and the rule are `aria-hidden`.
- Reduced motion: `loop()` returns immediately after calling `snap()`, which is `settle()` — index 0, progress 0, filter off. Still, unblurred type.
- `'use client'`, zero runtime dependencies, React 19 peer, MIT.
- The docs playground has a Code tab rendering the JSX for the current knob values, so "the playground is the generator" is literally true.
