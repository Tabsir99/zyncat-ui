## Rejected clusters

- **Typing speed tests, typing practice and typing jobs** - `text typing test`, `typing text test`,
  `typing text practice`, `free typing text`, `speed typing text`, `self typing test`,
  `text typing speed test`, `typing text game`, `auto typing club`, `how to auto type on typing club`,
  `text typing jobs` / `text typing remote jobs` / `zenfy text typing job`. Huge volume, held by
  typing.com and monkeytype; the intent is learning to type or getting paid to type, not animating text.
  Rejected outright - none of these appear anywhere in the copy.
- **Physical typewriters and typewriter meme GIFs** - `typewriter gif` and its whole tail
  (`kermit typewriter gif`, `snoopy typewriter gif`, `misery typewriter gif`, `the shining typewriter gif`,
  `jack torrance typewriter gif`, `monkey typewriter gif`, `naked lunch`, `murder she wrote`,
  `netflix wednesday`, `mc hammer`, `old typewriter gif`, `typewriter gif transparent`),
  `typewriter alternatives` in the buy-a-machine sense, and `free typewriter sound effects` (pixabay
  ranks #6 for `typewriter effect`). A picture or a sound of a machine, not a text animation.
- **Chat "user is typing" indicator** - `typing indicator`, `imessage typing indicator`,
  `whatsapp typing indicator`, `discord typing indicator`, `slack typing indicator`,
  `how to turn off typing indicator on iphone` (>100), `typing indicator animation`,
  `whatsapp cloud api typing indicator`, `react typing indicator`, `chat blinks`. Three animated dots
  in a chat bubble is a different component; TypingLines has no such mode, so claiming it would be false.
- **Handwriting-to-text conversion** - the entire `typed text` head: `convert handwriting to typed text`,
  `handwritten text to typed text`, `image to typed text`, `convert typed text to handwriting`,
  `read typed text out loud`, `how to recover typed text in chrome`, `how to edit typed text in pdf`.
  OCR and PDF tooling. `typed text` as a bare head is unusable because of it.
- **Auto-typers, autoclickers and broken keyboards** - `auto typing bot`, `auto typing extension`,
  `auto typing software for form filling`, `auto typing keyboard`, `how to fix keyboard auto typing`,
  `how to stop keyboard from auto typing`, `keyboard self typing`. Malware-adjacent utilities and
  hardware faults.
- **Blinking cursor as a boot failure or an editor setting** - `black screen with blinking cursor`,
  `blinking cursor on boot`, `blinking cursor windows 10`, `computer won't boot up blinking cursor`,
  `how to remove blinking cursor in vs code`, `why is my cursor blinking in google docs`,
  `how to stop the cursor from blinking`, `non blinking cursor`. Only the "what is the caret called"
  question and `typewriter cursor` survive from this seed.
- **Mouse and custom-cursor animation** - `cursor animation`, `mouse cursor animation`,
  `splash cursor animation`, `gsap cursor animation`, `neovim cursor animation`,
  `cursor.com landing page hero text`. Shares the word "cursor" and nothing else; the caret in a typing
  animation is not the pointer.
- **Terminal text editors and shell how-tos** - `best terminal text editor`, `linux terminal text editor`,
  `how to edit a text file in terminal`, `how to copy text from terminal`, plus the terminal-toy tail
  (`nyancat`, `parrot.live`, `pipes.sh`, `asciiquarium`, `sl steam locomotive`, `fallout 4 stuck in
