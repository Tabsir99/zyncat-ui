# Tag / TagGroup - @zyncat/ui/tag

Group: data-display
Docs: https://ui.zyncat.app/tag

User-owned label (a control, not a status).

icon, size, disabled, onRemove + removeLabel (removable). TagGroup wraps a labelled set.

```tsx
<Tag icon={<Icon name="hash" />} onRemove={fn} removeLabel="Remove design">
  design
</Tag>
```
